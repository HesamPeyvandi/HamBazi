## تغییرات
- `package.json` / `package-lock.json`: حذف ۴ پکیج. `npm ci` روی lock جدید بررسی شد.
- `next.config.mjs`: `/:dir(img|fonts|icons)/:path*` → `Cache-Control: public, max-age=2592000, stale-while-revalidate=86400`.
- `src/server/storage/index.ts`: `abortSignal: AbortSignal.timeout(20000)` برای `put`/`del` Blob.
- `src/db/client.ts`: `connect_timeout: 15`.
- بدون تغییر ظاهر، بدون migration، بدون متغیر محیطی جدید.

## پیشنهاد مؤثرتر که کد نمی‌خواهد
اگر سایت روی Vercel کند است، **منطقهٔ تابع‌های Vercel** (Project Settings ← Functions ← Region) را نزدیک منطقهٔ دیتابیس Neon بگذارید (مثلاً هر دو اروپا یا هر دو آمریکای شرقی). هر کوئری به دیتابیس رفت‌وبرگشت شبکه دارد و فاصلهٔ زیاد بین این دو معمولاً بزرگ‌ترین هزینهٔ سرعت است.
