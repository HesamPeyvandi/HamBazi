# تحویل فاز ۱

## ۱. چه چیزی ساخته شد
- **پایه:** Next.js 15 (App Router)، TypeScript، Tailwind 4، Drizzle + PostgreSQL، فونت Vazirmatn، هدر امنیتی و CSP.
- **محیط:** `APP_ENV` (dev/demo/production) با اعتبارسنجی در استارت (`src/instrumentation.ts`)؛ سرویس تنظیمات (`src/server/settings`).
- **فارسی‌سازی:** `src/lib/i18n/` — ارقام فارسی (یک ابزار مرکزی)، جلالی با `Asia/Tehran`، موبایل ایران.
- **دیتابیس:** ۱۸ جدول + ۳ مهاجرت (`drizzle/`).
- **ورود:** OTP شش‌رقمی، ذخیرهٔ هش (HMAC)، انقضا ۲ دقیقه، حداکثر ۵ تلاش، کولداون ۶۰ ثانیه، سقف ۵ درخواست در ساعت برای هر شماره و ۲۰ برای هر IP، کد جدید کد قبلی را باطل می‌کند. نشست: توکن تصادفی، فقط هش در DB، کوکی HttpOnly + SameSite=Lax، ۳۰ روز. ارائه‌دهندهٔ mock فقط dev/demo.
- **مجوز:** نقش‌ها + بررسی مالکیت سالن (`canManageVenue`) + جلوگیری از open redirect.
- **صفحات:** خانه، سالن‌ها (جستجو، فیلتر، مرتب‌سازی، لیست/کارت، صفحه‌بندی)، جزئیات سالن (گالری، سانس‌های هر روز، امکانات، قوانین، نظرات)، ورود، ثبت‌نام، تأیید OTP (+ حالت‌های خطا و ارسال مجدد)، آنبوردینگ با خودارزیابی مهارت، پروفایل، ویرایش پروفایل، شرایط و حریم خصوصی (متن نمونه — نیاز به بازبینی حقوقی)، ۴۰۴/خطا.
- **داده:** seed سمنان با ۸ سالن فرضی، اسلات ۱۰ روز آینده، ۹ کاربر.

## ۹. استقرار دمو روی Neon + Vercel (دستی)
1. **Neon:** پروژه بسازید ← از بخش Connection Details رشتهٔ اتصال **Pooled** را کپی کنید (`postgres://…-pooler…?sslmode=require`).
2. **مهاجرت و seed از کامپیوتر خودتان (یا همین پروژه):**
   ```bash
   DATABASE_URL='<رشتهٔ Neon>' npm run db:migrate
   DATABASE_URL='<رشتهٔ Neon>' APP_ENV=demo npm run db:seed
   ```
3. **Vercel:** مخزن را در GitHub بگذارید ← Import در Vercel (Framework: Next.js). متغیرهای محیطی:
   | نام | مقدار |
   |---|---|
   | `APP_ENV` | `demo` |
   | `DATABASE_URL` | رشتهٔ Pooled نئون |
   | `OTP_HMAC_SECRET` / `SESSION_SECRET` | هرکدام یک رشتهٔ تصادفی ≥ ۳۲ کاراکتر (`openssl rand -hex 32`) |
   | `SMS_PROVIDER` | `mock` |
   | `PAYMENT_MODE` | `disabled` |
   | `APP_URL` | آدرس `https://….vercel.app` |
4. Deploy بزنید و آدرس را باز کنید؛ باید نوار «محیط دمو» دیده شود و ورود با کد روی صفحه کار کند.
5. دامنه فعلاً ندارید؛ بعداً در Vercel ← Domains اضافه می‌شود (HTTPS خودکار).
6. **هزینه:** Vercel Hobby و Neon Free رایگان‌اند. توجه: Hobby طبق شرایط Vercel برای استفادهٔ غیرتجاری است؛ برای محصول واقعی باید Pro یا هاست دیگر در نظر گرفته شود. کرون روزانه تا فاز ۲ لازم نیست.
7. production واقعی را **فعلاً نسازید**: در `production` باید SMS واقعی تنظیم شود، وگرنه برنامه بالا نمی‌آید (عمداً).
