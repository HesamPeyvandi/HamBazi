# ۰۵ — سیستم طراحی RTL فارسی (Design System)

مقادیر رنگ از نمونه‌برداری مستقیم تصاویر مرجع به‌دست آمده‌اند و در فاز ۱ با تصویر اصلی (در وضوح کامل) دقیق‌تر می‌شوند.

## توکن‌ها

| توکن | مقدار تقریبی | کاربرد |
|---|---|---|
| `--brand-900` | `#013A33` – `#044336` | هدر تیره، هدر موبایل، بنرها |
| `--brand-600` | `#02834A` | دکمهٔ اصلی، تب فعال، لینک‌ها |
| `--brand-accent` | `#2EE07A` | کلمهٔ برجسته در هیرو (روی تیره)، لوگو |
| `--brand-50` | `#EAF7F1` / `#F2FBF8` | پس‌زمینهٔ تگ، کارت‌های اطلاعاتی |
| `--surface` | `#FFFFFF` | کارت‌ها |
| `--bg` | `#F7FAF9` | پس‌زمینهٔ صفحه |
| `--ink-900` | `#0F1F2E` (نیمه‌شب آبی-تیره) | تیتر |
| `--ink-500` | `#5B6B7A` | متن ثانویه |
| `--warn-bg/fg` | `#F8F3D6` / `#B7791F` | «در انتظار پرداخت» |
| `--info` | `#E6F0FF` / `#2563EB` | «در انتظار» |
| `--danger-bg/fg` | `#FEE8EB` / `#C53030` | «لغو شده» |
| شعاع | کارت ۱۴–۱۶px، دکمه/ورودی ۱۰–۱۲px، پیل کامل | |
| سایه | `0 1px 2px rgba(15,31,46,.06), 0 8px 24px rgba(15,31,46,.06)` | |

کنتراست: متن سفید روی `--brand-600` باید ≥ ۴٫۵ باشد؛ در فاز ۱ با ابزار خودکار بررسی و در صورت نیاز تیره‌تر می‌شود.

## تایپوگرافی
- **Vazirmatn** (مجوز OFL، قابل میزبانی شخصی) در وزن‌های ۴۰۰/۵۰۰/۷۰۰/۸۰۰؛ نسخهٔ variable، `font-display: swap`، زیرمجموعهٔ فارسی+لاتین، بارگذاری از دامنهٔ خودمان (نه CDN خارجی — مهم برای دسترسی از ایران).
- ارقام: خود فونت با فارسی‌سازی خروجی؛ **تبدیل ارقام فقط در یک ابزار مرکزی** (`lib/i18n/format.ts`)، نه فونت-فیچر.

## اجزای پایه
Button (primary/secondary/ghost/danger)، Input/Select/Checkbox/Radio/Toggle، DatePicker جلالی، Card، StatusPill، Tag، Rating (ستاره)، ProgressBar «۷ از ۱۰»، AvatarStack، Tabs، Stepper (انتخاب سانس ← تکمیل ظرفیت ← پرداخت)، Table→Cards در موبایل، Dialog/Sheet، Toast، Skeleton، EmptyState، بنر «محیط دمو»، نشان «پرداخت شبیه‌سازی‌شده».

پایه: Tailwind CSS + primitiveهای Radix (دسترس‌پذیری آماده)؛ کامپوننت‌ها در مخزن خودمان (الگوی shadcn).

## چیدمان و نقاط شکست
| نام | عرض | الگو |
|---|---|---|
| `sm` | < ۶۴۰ | موبایل: پیمایش پایین، کارت تک‌ستونه، فیلتر در Sheet |
| `md` | ۶۴۰–۱۰۲۳ | تبلت: ۲ ستون، سایدبار جمع‌شونده |
| `lg` | ۱۰۲۴–۱۲۷۹ | لپ‌تاپ: سایدبار فیلتر ثابت |
| `xl` | ≥ ۱۲۸۰ | دسکتاپ: حداکثر عرض محتوا ۱۳۶۰ |

- موبایل و دسکتاپ **طراحی جداگانه** دارند (مثلاً خانهٔ موبایل با آیکن ورزش‌ها در برابر نوار جستجوی افقی دسکتاپ).
- فقط **ویژگی‌های منطقی CSS** (`margin-inline-start`, `inset-inline-end`…)؛ بدون `left/right` سخت. lint-rule برای جلوگیری.
- مقادیر LTR (شماره تلفن، URL، کد OTP) با `<bdi dir="ltr">` / `unicode-bidi: isolate`.
- آیکن‌های جهت‌دار (فلش) در RTL قرینه می‌شوند.

## دسترس‌پذیری
فوکوس مرئی (حلقهٔ ۲px)، برچسب برای همهٔ فیلدها، `aria-live` برای خطاها و شمارندهٔ هولد، ناوبری کیبورد کامل در منو/دیالوگ/دیت‌پیکر، هدف لمسی ≥ ۴۴px، احترام به `prefers-reduced-motion`.

## قوانین
- هرگز تصویر مرجع به‌عنوان پس‌زمینه یا asset استفاده نمی‌شود؛ عکس‌های هیرو/سالن از فایل‌های جدا (seed) می‌آیند.
- لوگوی «هم‌بازی» (ابر/حلقهٔ سبز) در تصاویر دیده می‌شود؛ نسخهٔ برداری آن را من از روی مرجع بازسازی می‌کنم — اگر فایل لوگوی اصلی دارید بفرستید (سؤال ۴).
