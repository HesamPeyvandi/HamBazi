# فاز ۱۲-۳ — رفع پیام «برای این روز سانس خالی ثبت نشده است»

## علت
اسکریپت seed برای ۱۰ روز آینده (از زمان seed) سانس می‌سازد. پس از گذشت ۱۰ روز، همهٔ سانس‌های دمو در گذشته‌اند و صفحهٔ سالن برای تمام روزها این پیام را نشان می‌دهد. این موضوع به تغییرات فاز ۱۲-۲ مربوط نیست (کوئری `slotsForDay` و صفحه دست‌نخورده‌اند) و نیازی به برگشت نبود.

## راه‌حل
- `src/db/demo-slots.ts` — `extendDemoSlots(days)`: برای سالن‌های منتشرشده سانس‌های ۱۶:۰۰ تا ۲۲:۰۰ را با قیمت و طول هر سالن اضافه می‌کند. `onConflictDoNothing` روی ایندکس یکتا؛ هیچ‌چیز حذف یا تغییر نمی‌کند.
- `npm run db:slots [days]` — اجرای دستی.
- `DEMO_AUTO_SLOTS=1` — اجرای خودکار در build ورسل و کرون روزانهٔ `/api/cron/sweep` (فقط وقتی `APP_ENV` برابر production نیست).
- سالن‌های واقعی: مالک سالن سانس را در پنل خودش می‌سازد؛ این مکانیزم در production اجرا نمی‌شود.

## تأیید
`select max(starts_at) from time_slots;` باید تاریخی در ۱۴ روز آینده باشد.
